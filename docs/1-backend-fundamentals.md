# Backend Fundamentals

## What is Backend?

-Everything happening behind the scenes 
-Something without which nothing works
-Something that users cant see

---

## Browser

Browser is a mechanism that a user uses to ask for something, The user asks the browser for any request , the request from the browser goes on to the server , the server processes the request and get it back in form of a response from the database.

---

## Server

Server acts as a handler of requests which are made by the browser & replies back after getting the response or feedback from database.

---

## Database

It stores all the information which is needed to verify thr request made by the browser using server.

---

## API

Messanger b/w the browser and the server. example :- get,post,put,delete

---

## HTTP

Set of instruction that is made for the communication between a client(brower) & server

---

## Request

The asking of the client or browser can be said to be Request

---

## Response

The reply from the server after processing the request made by browser in the database.

---

## Node.js

Runtime env. that allows javascript to run outside the browser(mainly server)

---

## Express.js

A toolkit which is built on the top of node.js that makes building web servers much easier.

---

## npm

A package manager that lets you install many different packages which are being written by any other developer , manage their dependencies and run scripts along with other meta data also with the help of package.json file.

---

## package.json

The code which is witten by you depends on which packages are inside the package.json file.

---

## node_modules

A folder containing all the packages being installed by you through npm and it is not pushed to git repo as it can be installed be running npm install in the terminal.
